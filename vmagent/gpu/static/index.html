第一次使用 / 名词解释

第一次使用

  1. 点“使用内置场景 A 数据”。
  2. 时间模式选“快速模式”，点“开始实验”。
  3. 右侧观察完成数、资源曲线、服务器和任务状态。
  4. 结束后在左侧下载汇总、任务明细和资源曲线。

三个容易混淆的概念

提供负载：假设任务提交后立即运行，理想需求占容量的比例；可能超过 100%。

资源预留：实际分配和释放随时间的积分；不是 GPU SM 或 CPU 执行利用率。

等待 / 拒绝：等待是暂时没有足够资源；拒绝是单个任务在空节点上也永远放不下。

数据格式

服务器表：server_id, cluster_id, gpu_spec_public, gpu_count, cpu_capacity_cores。

任务表：pod_id, gpu_spec_public, gpu_request, cpu_request_cores, submit_time_sec, service_sec。
