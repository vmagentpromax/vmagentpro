## 口径

- 平均 JCT：所有任务的完成时间减提交时间，再除以任务数。
- Makespan：最晚完成时刻减最早提交时刻，包含最后一批任务的排空阶段。
- 平均等待：所有任务的开始时刻减提交时刻，再除以任务数。
- AGU：完整运行期间 GPU 请求份额的时间积分，除以 GPU 总容量与 Makespan 的乘积。它是资源预留率，不代表真实 GPU SM 利用率。
- AFR：完整运行期间发生联合资源碎片阻塞的时长占比。至少有一个任务等待，兼容节点的总空闲 GPU 与 CPU 都足够，但没有单台节点能同时满足该任务的 GPU 与 CPU 请求时，计为阻塞。
- 吞吐量：完成任务数除以 Makespan，换算成每小时任务数。包含 GPU 任务和 CPU-only 任务。

六项指标均按首个任务提交到最后一个任务完成的完整运行周期统计。转换清单给出的 6 小时窗口 AGU 与此处完整周期 AGU 采用不同分母，不应直接对比。

## 文件

- `metrics.csv`、`metrics.json`：汇总指标的机器可读副本。
- `reproduce_metrics.py`：从场景输入重新运行模拟并计算指标，使用 Python 标准库及仓库现有调度器代码。
- `provenance.json`：策略、时间窗口与输入文件 SHA-256。
- `reproduced_runs/`：每个场景的任务明细、事件时间线、节点终态及汇总结果。
- `五场景六项指标汇总.pptx`：可编辑的汇总表和口径说明。

从仓库根目录运行：

```powershell
python runs/allpods_20261025/metrics/reproduce_metrics.py
```
